# Hermest Board v0.3.0 Release Candidate

Hermest Board is a free, open-source (AGPL-3.0) tool for interactive storyboarding and AI-assisted video rendering.  
It runs in the browser and can be self-hosted for full local rendering. Local rendering needs a system
toolchain (ffmpeg/ffprobe, Chromium, Piper) — installed for you by `docker compose up` or
`scripts/install.sh`. No SaaS account, no per-render fee, and no cloud API is required for that path;
optional providers (ElevenLabs, FAL, Pexels, Pollinations) are opt-in and need network access.

## What works (VERIFIED)

**Interactive board**  
- Drag, rotate, scale cards, links, and photos.  
- Auto-saves to `localStorage`.

**Topic → source cards wizard**  
- Async draft/cancel flow.  
- Uses browser AI bridge: ChatGPT, Gemini, DeepSeek, Perplexity, or any OpenAI-compatible API (Ollama local, OpenRouter, Groq, Together, etc.).

**Multilingual voiceover**  
- Piper TTS (RU, EN, ES, DE, FR) locally and offline; ElevenLabs covers more languages but needs your own key and network.  
- Language is a project parameter, not hardcoded.  
- Timeline/SRT derived from measured audio duration; loudness normalization (loudnorm).

**Free visual generation**  
- Pollinations (no key required), opt-in toggle in render panel.

**Premium visuals + stock fallback**  
- FAL BYOK → Pollinations (free) → Pexels BYOK cascade.  
- Each source yields to the next with a warning in the manifest.

**Deterministic FFmpeg render**  
- The audio graph pins frame boundaries (`asetnsamples=n=1024:p=0`) so FFmpeg's threaded scheduler
  stops producing run-to-run drift in the mix; the render is driven entirely by the storyboard, with
  no sampling or randomness of its own. The filter-graph shape is asserted in tests; we do not claim a
  byte-identical MP4 across different FFmpeg builds or machines.  
- H.264/AAC MP4, 1920×1080 and 1080×1920.  
- SRT subtitles, manifest with hashes/provenance, SHA-256 sidecar.  
- Renders to a private directory under `/tmp`; no worker on public Vercel.

**Premium motion composition**  
- Branded motion frames, Ken Burns drift, b-roll under transparent overlay, music with auto-ducking.  
- Procedural CC0 music included in `assets/music/`.

**BYOK provider keys**  
- ElevenLabs, FAL, Pexels keys live only in worker process memory (`process.env`), never in project/localStorage/manifest.

**Separate AI assistant**  
- OpenAI-compatible assistant for board queries, using BYOK.

**Service worker**  
- Network-first strategy; aggressively caches only hashed `/assets/`.  
- `/src/` and `/` always fresh.

**Resume in-flight jobs**  
- Active draft/render IDs persisted in `localStorage`; reconnects on reload.

**Analytics block**  
- Duration, LUFS, size, scenes, voice, format, artifacts, SHA-256, copy summary.  
- Shown only on completed renders; hidden otherwise; works on mobile (375px).

**Workspace storage**  
- SQLite (node:sqlite) for clients, projects, campaigns, content, assets, jobs, notes.  
- Durable across restarts; JSON import/export intact.

**Multilingual editions**  
- Deterministic translation (temperature 0), `voice_missing` when no voice for a language, provenance in manifest.  
- UI “Create edition in [language]” (bulk all-languages and RTL are follow-ups).

**CI Gate**  
- 580+ unit tests, 6 real FFmpeg render tests, workspace integration tests, build, npm audit, smoke — all green on every push/PR.

**Docker images**  
- Static SPA image (`Dockerfile`) — frontend only, nginx.  
- Self-host image (`Dockerfile.selfhost`) — full worker with ffmpeg, chromium, piper; real MP4 rendering.

## Partial / not yet

- **Auto-publish to social platforms** — skeleton exists; OAuth token exchange/refresh/revoke not implemented. Board prepares publish pack; actual publishing requires durable storage and platform review.
- **Durable storage / multi-tenant auth** — guarded Postgres foundation and account-auth routes exist but are disabled by default. Full SaaS core is a separate phase.
- **Semantic shorts** — vertical render by aspect ratio works; meaning-based scene selection is planned.
- **Billing / quotas / metering** — not started.

## Install

**Self-host (full rendering)**  
```bash
docker compose up
```
Uses `Dockerfile.selfhost`; pass BYOK env vars as needed.

**Bare-metal (Debian/Ubuntu)**  
```bash
scripts/install.sh
```
Idempotent; installs ffmpeg, chromium, piper, and builds the project.

**Frontend-only static**  
```bash
docker build -t hermest-board .
```
See `docs/DEPLOYMENT.md` for the full deploy mode comparison.
