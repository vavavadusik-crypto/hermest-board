# Настольное приложение: запуск и приёмка

## Как запускается

Ярлык «Hermest Board» вызывает `scripts/hermest-desktop.sh`. Скрипт:

1. подхватывает BYOK-ключи из `~/.secrets/env.sh` — только `HERMEST_ELEVENLABS_API_KEY`,
   `HERMEST_FAL_API_KEY`, `HERMEST_PEXELS_API_KEY`, остальные секреты хранилища
   в окружение приложения не попадают;
2. ставит зависимости, если их нет, и собирает приложение, если сборки нет или
   исходники новее её;
3. выбирает свободный порт и поднимает локальный сервер на `127.0.0.1`;
4. дожидается, пока сервер ответит, и открывает окно приложения;
5. гасит сервер, когда окно закрывается.

Журнал: `~/.local/state/hermest-board/server.log`. Секретов в нём нет — из
хранилища туда пишутся только имена переменных.

Флаги: `--preview` (по умолчанию, собранная сборка) и `--dev` (dev-сервер vite
с горячей перезагрузкой).

Установить или обновить ярлык: `scripts/install-desktop-entry.sh`.

### Почему нельзя просто открыть index.html

Страница подключает модуль абсолютным путём `/src/app.js`, а конвейер рендера
живёт в vite-плагине как `/api/local-media/*`. По `file://` не существует ни
того, ни другого: открывается разметка, которая ничего не умеет. Замерено — та
же страница даёт 0 карточек через `file://` и 21 через `http://`.

Отдельный профиль браузера тоже не прихоть: с общим профилем `chrome --app`
передаёт запрос уже запущенному процессу и немедленно выходит, после чего
скрипт решил бы, что окно закрыто, и погасил сервер под руками у человека.

## Приёмка руками

Ниже — маршрут на час-полтора, который проходит через все живые части
продукта. Каждый пункт либо работает, либо даёт понятную ошибку; молчаливых
отказов быть не должно.

### Доска и проект
- [ ] Ярлык открывает приложение с карточками, а не пустую страницу.
- [ ] Карточка добавляется, переименовывается, перетаскивается, удаляется.
- [ ] Отмена и повтор действия возвращают доску в прежнее состояние.
- [ ] Проект сохраняется и открывается заново после перезапуска окна.

### Тема и длительность
- [ ] Тема вводится обычной фразой, длительность выбирается ползунком.
- [ ] Заданная длительность влияет на число сцен и объём текста.
- [ ] Невозможная длительность отклоняется до рендера, а не после.

### Сценарий
- [ ] Черновик доски собирается по теме.
- [ ] Правка словами меняет только то, о чём попросили.
- [ ] Модель, ответившая не-JSON, приводит к внятному отказу, а не к падению.

### Озвучка
- [ ] Локальный Piper озвучивает без ключей и без сети.
- [ ] Переключение на ElevenLabs подтягивает голоса аккаунта.
- [ ] Голос Aterna выбирается, сохраняется и слышен в кнопке «Прослушать».
- [ ] Без ключа интерфейс просит ключ, а не показывает пустой список молча.

### Рендер
- [ ] Рендер выдаёт MP4, SRT, обложку и манифест.
- [ ] Видео 1920×1080 при 60 кадрах, звук AAC 48 кГц.
- [ ] Субтитры не залезают под интерфейс площадки в вертикальном формате.
- [ ] Отмена рендера останавливает работу и убирает временные файлы.

### Провайдеры
- [ ] Ключ сохраняется на время сессии worker и не уходит в браузер.
- [ ] Ключ, добавленный в сессии, снимается кнопкой.
- [ ] Ошибка провайдера показывается кодом, без пересказа его ответа.

## Что заведомо не работает

- Экрана для коннекторов Figma и Canva нет: адаптеры есть, интерфейса к ним
  нет. Canva ни разу не проверялся против живого сервиса.
- Сериал запускается скриптом, а не из интерфейса.
- Публикация в площадки не подключена: продукт отдаёт файлы, загрузку делает
  человек.
